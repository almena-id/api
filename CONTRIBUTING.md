# Contributing

Thanks for helping with the Almena ID registry API. By taking part you
agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md). Security issues go
through [SECURITY.md](SECURITY.md), never through public issues.

## Getting started

You need [uv](https://docs.astral.sh/uv/) (it installs Python 3.13 if
missing), [Task](https://taskfile.dev) and Docker (for PostgreSQL and the full
stack).

```bash
task init    # creates .env from .env.example
task dev     # runs the API with auto-reload against PostgreSQL in Docker
task up      # the full stack in Docker
task --list  # everything else
```

[README.md](README.md) lists the configuration and endpoints;
[AGENTS.md](AGENTS.md) describes the layout of the code.

## Making a change

- Open an issue first for anything larger than a small fix, so the approach
  can be agreed before the code.
- Everything is written in English: code, comments, docs, commit messages.
- Code is formatted and linted with ruff and type-checked with mypy in strict
  mode.
- Schema changes come with an Alembic migration (`task db:revision -- "…"`);
  review the autogenerated file and make sure `downgrade` works.
- New behaviour comes with tests.
- Before sending a change, `task check` must pass: formatting, lint, types and
  all tests.

## Pull requests

Keep a pull request to one topic, describe what it changes and why, and link
the issue it addresses. By contributing you agree that your contribution is
